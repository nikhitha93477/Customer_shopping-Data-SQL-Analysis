# Customer Shopping Data Analysis

## Project Overview
This project analyzes customer shopping
data using MySQL.

## Tools Used
- MySQL
- SQL
- GitHub

## Project Objectives
- Analyze customer shopping behavior
- Identify top-selling categories
- Analyze gender-wise shopping
- Study age-wise customer behavior
- Analyze payment methods
- Compare shopping mall sales
- Analyze monthly sales
- Identify top 10 customers

## SQL Concepts Used
- SELECT
- WHERE
- GROUP BY
- ORDER BY
- COUNT
- SUM
- AVG
- MAX
- MIN
- CASE
- LIMIT
- DISTINCT

## Conclusion
This project helps understand customer
shopping patterns and sales performance.
